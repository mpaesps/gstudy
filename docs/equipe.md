# Organizacao Da Equipe

## Divisao

- Pessoa 1: backend, autenticação, usuários e permissões.
- Pessoa 2: backend, tutorias, metas, frequência, Projeto de Vida e alertas.
- Pessoa 3: frontend, layout, dashboards, formulários e responsividade.
- Pessoa 4: banco, documentação, testes, MER e apresentação.

## Fluxo De Trabalho

- Planejamento semanal.
- Quadro Kanban com `A fazer`, `Em andamento`, `Revisao` e `Concluido`.
- Toda tarefa deve ter issue.
- Toda entrega deve passar por pull request.
- Cada integrante deve explicar suas decisões técnicas na apresentação.
