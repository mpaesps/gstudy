# Regras De Negocio

## Tutorias

- Toda tutoria deve possuir tutor responsável.
- Tutorias individuais devem ter exatamente um aluno.
- Tutorias coletivas podem ter vários alunos.
- Toda tutoria concluída deve ter observação pedagógica.
- Ao concluir uma tutoria, a frequência deve ser registrada para todos os participantes.

## Histórico

- O histórico pedagógico deve ser preservado.
- Registros importantes não devem ser apagados fisicamente.
- Para usuários, o sistema usa inativação em vez de exclusão definitiva.

## Permissões

- Aluno visualiza apenas seus próprios dados.
- Tutor registra tutorias e acompanha alunos sob sua responsabilidade.
- Coordenação visualiza dashboards globais, relatórios e usuários.
- Admin possui controle total.

## Alertas

O sistema deve identificar:

- Alunos sem tutoria concluída nos últimos 30 dias.
- Frequência abaixo do limite pedagógico.
- Metas vencidas.
- Tutorias agendadas não registradas.
- Queda de desempenho acadêmico.
